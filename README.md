# 🧹 Dirty Data Cleaning Project

This project focuses on cleaning and analyzing a messy real-world dataset from Kaggle.

## 🧾 Dataset
[Dirty Data to Clean - What's Wrong With This Dataset?](https://www.kaggle.com/datasets/joannanplkrk/dirty-data-to-clean-whats-wrong-with-this-dataset)

## 🧼 Project Steps
1. Load the dataset
2. Clean nulls, duplicates, and inconsistent values
3. Perform exploratory data analysis (EDA)
4. Create visualizations
5. Summarize insights

## 🛠️ Tools Used
- Python
- pandas
- matplotlib / seaborn
- Jupyter Notebook
