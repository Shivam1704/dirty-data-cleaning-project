# 🧹 Dirty Data Cleaning Project

This project focuses on cleaning and analyzing a real-world messy dataset sourced from Kaggle. The dataset contains typical data quality issues that often occur in business and research settings, such as duplicates, missing values, inconsistent entries, and formatting problems.

---

## 📊 Dataset Overview

- **Title**: [Dirty Data to Clean – What's Wrong With This Dataset?](https://www.kaggle.com/datasets/joannanplkrk/dirty-data-to-clean-whats-wrong-with-this-dataset)
- **Author**: Joanna N
- **Size**: ~23 KB (CSV)
- **Content**: Tabular data with mixed types and inconsistencies
- **Purpose**: Practice data cleaning, preprocessing, and exploratory data analysis (EDA)

---

## 🚀 Project Objectives

1. Load the raw dataset
2. Perform data cleaning:
   - Handle missing values
   - Remove duplicates
   - Correct data types and formatting
   - Standardize categorical data
3. Conduct exploratory data analysis (EDA):
   - Summary statistics
   - Value distributions
   - Correlations
4. Create visualizations to better understand:
   - Trends
   - Anomalies
   - Cleaned vs raw data comparison
5. Summarize actionable insights
